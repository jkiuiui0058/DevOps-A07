# 错误码

MD/RD 是正常完成的检测结果，应写入 `ERROR_REPORT`，不能写入 `job.error`。只有任务未能正常完成时才使用以下错误码。

| 错误码 | 含义 | 建议处理 |
| --- | --- | --- |
| `ENV_3002` | 镜像构建或环境准备失败 | 由环境提供方检查镜像与日志 |
| `EXEC_4002` | 执行超时 | 调整时间限制或构建配置 |
| `ANALYSIS_5001` | 分析器执行失败 | 检查分析日志 |

上述三个编码与 B07 当前共享 Schema 一致。请求格式、基线不匹配、Artifact 校验和跟踪失败等更细的 A07 编码暂不加入共享枚举，应先与 B07 确认；在此之前通过 `message` 和 `details` 表达具体原因。
