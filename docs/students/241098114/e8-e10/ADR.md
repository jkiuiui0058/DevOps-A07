## 缓存失效与配置身份绑定

- 普通函数体变化可能保留 key，从而复用实际依赖图；这不代表 Make 无须重编译。
- 任一预处理指令变化，包括条件守卫变化，都会使全局 key 失配。
- 配方、允许的 flags 和编译器版本首行参与 key；实际运行仍须绑定镜像ID与工具链记录。
- 仅声明变化不必失效实际图，但必须用当前声明重算 MD/RD。
- JSON 中 commit 为样例内部 HEAD；外层学生源码 SHA、工作区差异/摘要另行记录。未提交新测试不能仅由旧 HEAD 标识。
