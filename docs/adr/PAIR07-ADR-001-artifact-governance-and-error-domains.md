# PAIR07-ADR-001：Artifact 治理与错误码分域

- 状态：已接受
- 日期：2026-09-22
- 决策方：A07、B07

## 背景

`artifact://pair07/<job>/<file>` 已作为跨组逻辑引用，但实际读取、保留、权限和错误码扩展仍需形成最终交接约定。

## 决策

1. Artifact 以 `GET /v1/artifacts/{pair}/{job}/{file}` 作为统一读取入口。成功响应返回原始字节、正确的 `Content-Type` 和 `X-Artifact-Sha256`；未找到或已过期返回 404，跨 pair 返回 403。共享目录仅可作为服务内部实现。
2. 平台统一执行 GC。Job 进入终态后产物保留 30 天，但只要仍有 Job 引用该产物就不得删除。`pair07` 内 A07/B07 只读互访。
3. `ENV_*`、`EXEC_*` 是平台共享域，新增编码须双方确认；`ANALYSIS_*` 是 A07 专有域，可由 A07 扩展。消费者必须原样记录并容忍未知错误码，不得因无法识别而崩溃。

## 理由

HTTP 入口提供统一、可审计的读取证明，又不要求消费者耦合生产方目录或存储。平台统一 GC 才能在清理前检查所有 Job 引用。错误码按前缀划分所有权，可减少无关协商，同时以消费者宽容保证兼容性。

## 代价与后续

E2 只约定接口形状；服务端和 GC 在 E12 实现。保留时长以后如需调整，必须更新共同决策，但引用不变式不得放宽。
